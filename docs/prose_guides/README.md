## Horoscope Application

For Daily, Weekly, Sun Sign, and Cosmic Weather surfaces, these guides should be
treated as editorial constraints:

- Translate machinery into lived-life language by default.
- Name the mechanism when it helps the reader understand why they received a
  particular activation or timing note.
- Make each prose block add one new kind of value: orient, locate,
  differentiate, complicate, translate, sequence, support discernment,
  integrate, or reframe.
- Avoid generic caution loops, decorative vagueness, and repeated practical
  advice across nearby blocks.
- Keep deterministic future-fact claims out of production surfaces.

These files are prose standards only. They do not alter schemas, selectors,
formulas, report generation, or rendering unless a separate implementation task
explicitly makes that change.
