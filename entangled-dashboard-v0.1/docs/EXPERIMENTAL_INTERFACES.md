# Experimental Interfaces

Experimental interfaces are optional remixes of completed readings.

## Wordfall

Turns keywords, astrology terms, and profile lens phrases into a stream of words. The user can freeze selected words and save them as reflection material.

## Abstract Readout

Turns a packet into a sigil, radial glyph map, color field, circuit mandala, or constellation-like view. It intentionally explains very little.

## Speculation Matrix

A compositional rule tree:

- If a symbol appears with another symbol, suggest a possible relationship.
- If live astrology reinforces a symbol, name the reinforcement.
- If the profile lens highlights a channel, route the emphasis.

The matrix is rule-based without pretending to be deterministic fate.
