# Product Spec

## Identity

The Entangled Dashboard is a symbolic dashboard for standard tarot, standard runes, live astrology, personal astro routing, optional OpenRouter synthesis, and experimental modern oracle interfaces.

It is not entropy-based. It does not claim that a field chose the result. It does not reduce the reading to a canned lookup.

## Product Split

```text
The Entangled Dashboard
  Standard Practice
    Tarot
    Runes
  Synthesis Layer
    Live Astrology
    Profile Lens
    OpenRouter Synthesis
    Oracle Chat
  Experimental Interfaces
    Wordfall
    Abstract Readout
    Speculation Matrix
    Archive / Pattern View
```

## v0.1 Scope

- Dashboard shell.
- Tarot tab using JSON.
- Rune tab using JSON.
- Basic reading packet system.
- Live astrology adapter scaffold.
- Local synthesis renderer.
- Optional OpenRouter synthesis.
- LLM status and graceful fallback.
- Archive.
- First-pass experimental remixes.

## Future Versions

v0.2 should deepen freehand rune casting, profile lens routing, specialized astrology readings, oracle chat for the current packet, and source trace transparency.

v0.3 should deepen Wordfall, Abstract Readout, Speculation Matrix, reading-to-visual remixing, and archive pattern detection.
