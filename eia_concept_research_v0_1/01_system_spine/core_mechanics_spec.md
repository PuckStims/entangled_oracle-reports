# Core Mechanics Spec v0.1

## Core formula

```text
EIA Output = Natal Architecture + Symbolic Grammar + Current Dynamics + State Snapshot
```

Where:

```text
Natal Architecture
  Stable baseline derived from natal astrology and EO-compatible chart calculations.

Symbolic Grammar
  Tarot/archetype correspondences used as language families and interpretive grammar, not as permanent random identity.

Current Dynamics
  Polarity-inspired positive / negative / neutral current model, elemental balance, load, threshold, and restoration language.

State Snapshot
  Optional entropy-derived tarot/rune/lots reading that describes the active in-the-moment field.
```

## Product modes

### 1. Birth Architecture

Stable baseline report.

Input:
- birth date
- birth time
- birth location
- birth-time confidence

Output:
- seven-register architecture
- dominant and secondary modes per register
- mechanism, distortion, restoration, experiment
- optional EAS mythic overlay

### 2. State Overlay

Moment-specific report.

Input:
- baseline architecture
- current transits, if astrology layer is active
- entropy-derived seed from app/environmental snapshot
- tarot/rune/lots draw generated from locked entropy seed
- optional user check-in

Output:
- active register(s)
- current distortion risk
- current restoration key
- suggested experiment for the moment/week

## Seven-register architecture

Every EIA report is organized through seven registers:

1. **Ignition Register** - how movement begins.
2. **Reception Register** - how signal enters the system.
3. **Decision Register** - how clarity becomes trustworthy.
4. **Current Register** - how energy moves and spends.
5. **Boundary Register** - how selfhood holds shape under contact.
6. **Contact Register** - what the field does in relationship, group, audience, or intimacy.
7. **Restoration Register** - how coherence returns.

## Output grammar per register

Each visible register block must include:

```text
Mode
  The strongest operational pattern.

Secondary Mode
  A supporting or modifying pattern when score confidence warrants it.

Mechanism
  How the pattern operates when coherent.

Distortion
  How it misfires under pressure.

Restoration
  What brings the system back online.

Experiment
  A practical 3-7 day test, framed as observation rather than obedience.
```

## Rules that keep EIA distinct

- EIA does not use centers, gates, channels, types, strategy, authority, profile, incarnation cross, or BodyGraph structure.
- EIA does not frame itself as a genetic code or fixed energetic blueprint.
- EIA is an operational model: it describes mechanism, distortion, repair, and experiment.
- Tarot/lots/runes are state overlays, not permanent design components.
- Biophysics and quantum language are metaphors for signal, load, threshold, measurement, probability, and coherence - not literal proof claims.
- Odic force is historical/aesthetic inspiration for a field-sensitivity layer, not a measurable claim.

## Report-level algorithm

```text
1. Calculate natal chart.
2. Extract astrological feature vector.
3. Calculate existing EO/EAS indexes where available.
4. Score each EIA register mode using weighted rules.
5. Apply confidence thresholds.
6. Select dominant mode and optional secondary mode per register.
7. Generate mechanism, distortion, restoration, and experiment from content pack.
8. Build Architecture Summary.
9. Add optional EAS mythic overlay.
10. Add optional entropy-derived State Snapshot if requested.
```

## Confidence and suppression logic

EIA should inherit the useful EAS scarcity principle: do not force every possible signal to appear.

Suggested thresholds:

```text
0.00 - 0.29: suppress mode
0.30 - 0.49: subtle modifier only
0.50 - 0.69: display as secondary mode
0.70 - 1.00: display as dominant mode
```

Display rules:

- Each register must have one dominant mode.
- Secondary mode appears only when above threshold.
- Tertiary modes are engine-only unless a practitioner appendix is requested.
- Contradictions are not errors; they are integration sites.

## Contradiction handling

If two modes score closely but imply opposite strategies, render them as a dual mechanism rather than choose falsely.

Example:

```text
Decision Register: Immediate Knowing + Tidal Review
Your first recognition may be fast, but the final decision becomes cleaner after the feeling system has had time to catch up.
```

This is one of EIA's strongest advantages over rigid typology.
