# Source Layer Matrix

## Purpose

This document assigns each source tradition to a specific function in EIA so the system does not collapse into a vague synthesis blob.

| Source layer | EIA role | Stable baseline? | State overlay? | User-facing claim level |
|---|---|---:|---:|---|
| Natal astrology | Architecture feature vector | Yes | Yes, via transits | Symbolic timing/pattern system |
| Existing EO/EAS | Mythic resonance and proprietary pattern depth | Yes | Yes | EO-native interpretive layer |
| Tarot | Symbolic grammar and optional state draw | No, except correspondences | Yes | Archetypal language / reflection |
| Runes/lots | Spatial/somatic field snapshot | No | Yes | Moment-specific divination overlay |
| Polarity Therapy | Current-flow metaphor | Yes | Yes | Positive/negative/neutral current model, nonmedical |
| Odic force | Historical field-sensitivity aesthetic | No | Optional | Historical/esoteric metaphor, not measurable claim |
| Biophysics | Grounding vocabulary | Yes | Yes | Legit scientific field; metaphorical terms only |
| Quantum mechanics | Measurement/probability metaphor | No | Yes | Strict metaphor unless mathematically implemented |
| User check-in | Calibration | No | Yes | Self-report/contextual tuning |

## Rule of inclusion

A source layer must do one of five jobs:

1. Calculate baseline architecture.
2. Provide symbolic grammar.
3. Modify current-state activation.
4. Ground language in usable body/system metaphors.
5. Produce a practical experiment.

If it does not do one of these jobs, it belongs in research notes, not the engine.

## Layer responsibilities

### Astrology

Astrology provides stable baseline features: placements, houses, aspects, element/modality balance, chart ruler condition, angles, and timing/transit activation.

### Tarot

Tarot provides symbolic vocabulary and dynamic state overlay. It should not decide permanent architecture.

### Lots/runes

Lots and runes can provide spatial, tactile, or entropy-derived snapshots. They can identify what part of the architecture is loud now.

### Polarity

Polarity provides a current model: output/reception/integration. Translate it into EIA's language of charge, flow, threshold, load, and return.

### Odic

Odic material contributes historical texture to a field-sensitivity layer. Do not claim the force is measurable.

### Biophysics

Biophysics contributes language: signal, threshold, load, coherence, system, regulation, noise, recovery curve.

### Quantum

Quantum concepts contribute metaphor: state, observation, probability, measurement event, contextual outcome. Do not imply tarot is literally quantum mechanics.
