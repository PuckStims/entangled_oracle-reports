# Visual Language

## Visual design goal

EIA should look like:

> circuit board + altar cloth + nervous system map + astrological instrument.

It must not resemble a Human Design BodyGraph.

## Recommended visual systems

### 1. Seven-register dashboard

A clean panel with seven vertical registers.

Each register shows:

- icon
- mode name
- score/confidence band
- current direction: output / reception / neutral
- distortion marker
- restoration marker

Best for: PDF reports and web app.

### 2. Concentric architecture map

A circular map:

```text
Center: Core signal
Ring 1: Ignition / Reception / Decision
Ring 2: Current / Boundary / Contact
Ring 3: Pressure / Restoration / World Expression
Outer field: State Snapshot / transits / environment
```

Best for: premium report visual.

### 3. Circuit-mandala hybrid

Seven nodes connected by signal paths.

Nodes:

- Ignition
- Reception
- Decision
- Current
- Boundary
- Contact
- Restoration

Signal can be shown as lines, pulses, or illuminated pathways.

Best for: brand identity and app dashboard.

### 4. Polarity compass

Triangle or three-pole diagram:

- Positive / outward current
- Negative / receptive current
- Neutral / integrating current

Best for: Current Register explainer.

## Icon concepts

| Register | Icon direction |
|---|---|
| Ignition | spark, match, opening gate, arrow from center |
| Reception | antenna, bowl, moon, open hand |
| Decision | compass, scale, click-lock, lens |
| Current | wave, battery, flame, spiral |
| Boundary | membrane, gate, blade, ring |
| Contact | bridge, node network, mirror, pulse field |
| Restoration | root, lantern, cup, bed, ritual circle |

## Color logic

Avoid copying chakra-center rainbow layouts.

Possible palette logic:

- Ignition: warm accent.
- Reception: cool/soft accent.
- Decision: clear/bright accent.
- Current: luminous/charged accent.
- Boundary: high-contrast line accent.
- Contact: relational/network accent.
- Restoration: grounded/deep accent.

Keep colors brand-specific and not mapped to HD centers.

## BodyGraph avoidance checklist

- No human silhouette.
- No nine centers.
- No connected body centers.
- No colored/white definition logic.
- No gate/channel numbering system.
- No mandala that uses HD structure.
- No direct Type/Strategy/Authority/Profile display equivalents.
