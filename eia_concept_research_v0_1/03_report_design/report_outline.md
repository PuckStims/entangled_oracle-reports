> This report maps symbolic operating patterns using natal astrology, EO internal architecture scoring, polarity-inspired current modeling, and optional state overlays. It is a reflective framework, not a diagnosis, command system, or substitute for lived context and real-world information.

## Page/section structure

### 1. Architecture Summary

A one-page dashboard:

- Ignition Register: dominant mode + one-line mechanism.
- Reception Register: dominant mode + one-line mechanism.
- Decision Register: dominant mode + one-line mechanism.
- Current Register: dominant mode + one-line mechanism.
- Boundary Register: dominant mode + one-line mechanism.
- Contact Register: dominant mode + one-line mechanism.
- Restoration Register: dominant mode + one-line mechanism.

### 2. Signal System

Covers:

- Ignition Register
- Reception Register
- Decision Register

Purpose:

Explain how the person starts, receives, and knows.

### 3. Capacity System

Covers:

- Current Register
- Restoration Register

Purpose:

Explain energy rhythm, capacity, depletion risks, and return practices.

### 4. Contact System

Covers:

- Boundary Register
- Contact Register

Purpose:

Explain how the person meets others, absorbs/filters pressure, makes agreements, and affects relational fields.

### 5. Pressure + Distortion System

Covers:

- top 2-4 distortion patterns across registers
- how each distortion presents
- practical correction

Possible distortion names:

- Premature Yes
- Urgency Collapse
- Over-Translation
- Caretaker Drift
- Control Lock
- Signal Flood
- Collapse into Ambiguity
- Fortress Reflex
- False Certainty

### 6. Restoration Keys

Covers:

- primary restoration mode
- secondary restoration mode
- emergency low-spoons version
- weekly practice
- relational support script

### 7. World Expression

Covers:

- how the architecture becomes vocation, creativity, leadership, service, devotion, or public contribution
- inherited fluency and growth direction if using Soul Ecosystem material

### 8. Mythic Overlay, optional

EAS remains valuable as mythic resonance:

- dominant mythic current
- secondary current
- how myth modifies architecture
- not the skeleton of the report

### 9. State Snapshot, optional

If entropy-derived divination is included:

- seed/method note
- active register
- state symbol
- current distortion risk
- restoration key
- 3-7 day experiment

### 10. Technical Appendix

- natal positions
- house system
- birth-time confidence
- scoring table by register
- source layer breakdown
- glossary

## Visual hierarchy

The user should leave the report remembering:

1. How I know.
2. How I spend/recover energy.
3. How I hold boundaries.
4. What distorts me.
5. What restores me.

Everything else supports that.
