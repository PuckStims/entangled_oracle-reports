# Predictive Sandbox JSON Library

## Purpose

This library is an R&D / speculative content lane for
`predictive_sandbox`.

It does **not** need to inherit the full astro-psych center of gravity
used by main EO product surfaces. It should support more varied
predictive expression while staying downstream of actual engine evidence.

## Working principle

- scaffold first
- sort content second
- write at scale third

## Content buckets

1. `10_copy_entirely`
   Use for blocks that already function as predictive sandbox language
   with little or no rewriting.
2. `20_modify_from_existing`
   Use for EO blocks with useful structure but too much mainline voice,
   identity-focus, or therapeutic framing.
3. `30_new_writes`
   Use for sandbox-native predictive content that EO does not already
   express well.

- `id`
- `scope`
- `family`
- `mode`
- `conditions`
- `title`
- `body`
- `tags`
- `notes`

## Routing guidance

Entries should route from computed sandbox evidence such as:

- `semantic_state`
- `dominant_operation`
- `gradient`
- `lifecycle_route`
- `pass_state`
- `method_family`

Later expansions may also route from:

- `confidence_state`
- `angle_eligibility`
- `polarity`
- `coalition`
- `counterforce`
- `complexity`

## What to avoid early

- defaulting back to astro-psych interpretation
- prose that invents new predictive logic
- therapeutic or identity-development framing as the main expression
- overfitting the library to one narrow EO narrative tone

## Writing target

Aim for predictive behavior and event texture:

- situational pressure
- timing openings / slowdowns
- disruption / redirection
- practical consequences
- exposure / revelation
- thresholds / crossings
- aftermath / residue
- ambient or public-facing atmosphere
